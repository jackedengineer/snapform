# Respondent session HTTP boundary

29 October 2026. Anonymous session creation and scoped reads now run through Express on the real Worker bridge. The client prepares its identity/capability before creation; SQL migration 0012 makes concurrent retries reuse one existing admission. The API requires a dedicated bearer credential, strict 16 KiB JSON, exact UUID routes, same-origin mutation checks, native start/read limits and server-side Turnstile validation. Compiled definitions remain pinned; unsupported file forms fail closed and rejected creation rolls back.

Verification: 158 unit tests pass; core coverage remains 100% lines/functions, 99.74% statements and 99.35% branches. The full 25 rollback-only Neon tests pass. All 58 Worker tests pass. Boundary tests cover malformed/oversized/foreign-origin requests, cookie fallback refusal, production rejection of dummy keys and native rate limits. No dependency was added. Production client assets remain 188.99 KiB gzip JS, 5.46 KiB CSS and 36.07 KiB primary font, within the unchanged budgets.

The first live preview probe caught a real runtime defect: Workers rejects fetch redirect mode `error`, before making a network request. Node accepted it and mocked transports hid it. Two regression assertions first failed; the provider request now uses `manual` and rejects non-2xx responses, including redirects. A test constructs the actual Worker Request before returning a synthetic redirect. Temporary diagnostics were removed. See [Cloudflare's Request documentation](https://developers.cloudflare.com/workers/runtime-apis/request/).

The repeated real HTTP probe passed concurrent duplicate starts with identical session/expiry/snapshot, no capability echo, no-store reads, wrong public/session/hash rejection, account-cookie refusal, no creator-account promotion, unknown-key rejection, version pinning across republish and unpublish revocation. It used Cloudflare's official local dummy challenge key and the approved owner's scratch form; it restores the original definition, deactivates only its own publication and signs out only its own session. Synthetic session reservations expire normally; immutable version history is retained.

Browser regression: the existing agency editor reloads with its saved title, ten blocks, two pages, three rules and “All changes saved.” No respondent UI exists in this slice, so the HTTP probe is not represented as normal/power/adversarial collector-browser verification. Actual production widget configuration, challenge solving, answer persistence, durable submit and collector workflows remain upcoming gates. [ADR-020](../decisions/ADR-020-retryable-intake-creation.md) records the protocol and retry policy.
