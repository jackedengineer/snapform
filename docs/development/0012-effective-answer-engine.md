# Effective answers and forward routing

28 October 2026. The shared engine compiles a definition, validates an owned field map and evaluates applicability in field order. It visits only the selected forward page path, chooses the first matching navigation rule by priority and records evaluated rule outcomes for inspection. Requiredness applies only to effective visible fields. Only decoded value states appear in the normalized payload; zero and false are preserved, while hidden/skipped/refused/blank values are not exported.

An upstream correction cascades through dependent visibility rules. Skipped-page answers become not applicable. Re-evaluating an unchanged effective state is idempotent. A regression test first found that revealing a previously hidden field produced a generic invalid-answer error. The engine now treats its exact prior internal not-applicable state as missing, requiring a fresh answer without resurrecting its old value. Direct codec input still rejects respondent-declared applicability. State owners must persist/reuse the recomputed effective state after each change rather than retaining hidden values as a latent answer buffer.

Tests cover default, jump and ending paths; priority; nonmatching rules; cascade and re-entry; stale hidden data; invalid definitions/maps; typed comparisons; and missing required fields. All 101 unit tests and 39 workerd tests pass, including the same zero-valued fixture evaluated inside the Worker. Measured pure-core coverage: 100% lines/functions, 99.71% statements and 99.25% branches. Strict checks and production builds pass; current emitted client JS stays 167.44 KiB gzip because this engine is not yet imported by visible application routes.

No claim of durable draft saves, publication or respondent submission is made here. Those features will consume this same engine, with their own real database/API/browser gates. File references still require collection-time ownership and scanner checks; AI confirmation/provenance is not replaced by ordinary field validation.
