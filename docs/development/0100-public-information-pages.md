# Public support, privacy and abuse information

The public /support, /privacy and /report-abuse pages use the approved contact
trainwithchirag@gmail.com. They describe the actual private preview, distinguish
the collecting business from the service and disclose unfinished deletion
controls. They make no certification, legal-entity, guaranteed support-time or
complete recovery claim. Privacy copy distinguishes seven-day recovery
availability from browser data cleanup, which happens on a later collection
open or through browser site-data controls.

Home and authentication footers link to these pages. Collector links open a
separate tab with an announced new-tab label, preserving the active conversation.
Native semantic landmarks/headings, real links and existing typography/color
tokens provide the layout; no dependency or animation library is added.

Production SSR availability assertions failed before implementation and pass
with the real web/Express/Jobs preview boundary. Browser QA passed normal,
keyboard and adversarial navigation, mobile/desktop visual review and 27 bounded
structural assertions. A discovered 404 skip-link target defect was reproduced
through native HTTP, fixed in the root not-found/error markup and verified in
HTTP and the browser. The exception screen itself was not induced. Detailed
expected/observed results and limitations are recorded in 0099.

Strict checks, production builds and bundle gates pass. Generated route changes
were reviewed separately. Total client JS is 208.05 KiB gzip and CSS is 8.59 KiB;
both remain within the unchanged budgets. Public contact delivery/monitoring, legal review,
active purge/recovery and the overall launch gates remain separate unfinished
work; a public contact link alone does not complete those workflows.
